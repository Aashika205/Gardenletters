Privacy and security

Accounts use Supabase Auth. Row Level Security in the database lets each person read only their own records. We never ask for bank passwords or card numbers, and nothing is sent to AI services. This site is hosted publicly on GitHub Pages, so anyone can view the page source; your financial data is not in it.
